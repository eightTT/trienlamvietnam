# Triển Lãm Việt Nam - Vietnam Culture & Pride

A responsive web page showcasing Vietnamese culture, history, and natural beauty. Built with plain HTML, CSS, and vanilla JavaScript.

## 🇻🇳 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Hamburger Menu**: Mobile-friendly navigation with smooth animations
- **Trending Slideshow**: Auto-playing slideshow with manual controls, keyboard navigation, and touch support
- **Vietnam Color Scheme**: Red (#DA251D), Yellow (#FFCD00), and Green (#2F8B3D) gradients throughout
- **CSS Animations**: Smooth transitions, fade-ins, slides, and hover effects
- **No Dependencies**: Pure vanilla JavaScript - no frameworks required

## 🎨 Content Sections

1. **Hero Section** - Welcome banner with Vietnam flag colors
2. **Trending Slideshow** (Tin Tức Nổi Bật) - Featured news and highlights
3. **National Ceremonies** (Lễ Hội Dân Tộc) - Traditional festivals
4. **History Timeline** (Lịch Sử Bảo Vệ Đất Nước) - Vietnam's defense history
5. **People's Army** (Quân Đội Nhân Dân) - Military heritage
6. **Culture** (Văn Hóa Việt Nam) - Traditional arts and customs
7. **Natural Beauty** (Vẻ Đẹp Thiên Nhiên) - Photo gallery of landscapes

## 🚀 Usage

Simply open `index.html` in a web browser. No build process or server required!

For development with live reload:
```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx http-server

# Then open http://localhost:8000
```

## 🎯 Slideshow Features

- **Auto-play**: Advances every 5 seconds
- **Manual controls**: Previous/Next buttons
- **Keyboard navigation**: Arrow keys to navigate
- **Touch support**: Swipe on mobile devices
- **Pause on hover**: Stops auto-play when hovering
- **Dot indicators**: Shows current slide position

## 🎨 Design Guidelines

### Colors
- Primary Red: `#DA251D` (Vietnam flag red)
- Star Yellow: `#FFCD00` (Vietnam flag yellow)
- Accent Green: `#2F8B3D` (Representing nature)

### Typography
- Headings: Georgia, Times New Roman (serif)
- Body: Segoe UI, Tahoma, Geneva, Verdana (sans-serif)

### Breakpoints
- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px

## 🎭 Animations

All animations are CSS-driven for better performance:
- Fade-in on page load
- Slide-in for timeline items
- Zoom effects on cards
- Hover transitions
- Smooth scrolling

## 🔧 Customization

To customize content:
1. Edit text in `index.html`
2. Modify colors in `styles.css` (`:root` variables)
3. Add/remove sections as needed
4. Replace SVG images with your own in the `images/` folder
